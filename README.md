# 营救飞飞 🎮
HTML5 Canvas 平台跳跃闯关小游戏，单文件无外部依赖，支持电脑键盘、手机触屏双端游玩。

## ✨ 项目特性
- 纯前端单HTML文件，CSS、JS全部内嵌，断网本地打开即可游玩
- 电脑端：左右方向键移动，空格键跳跃
- 移动端：屏幕底部虚拟按钮，触屏直接操作
- 内置3种难度模式可选
- 游戏机制：拾取黄色豆子永久提升移速；得分越高，幽灵移动速度越快
- 物理引擎：重力、跳跃、AABB碰撞检测，关卡逐步提升难度

## 🚀 运行方式
1. 下载仓库内 `index(2).html`
2. 使用现代浏览器直接打开文件，无需额外安装依赖、无需服务器
> 部署至GitHub Pages后，可直接通过在线网址游玩。
